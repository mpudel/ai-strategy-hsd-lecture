# Setup Before the Lecture

Please complete these steps **before the first session**. It takes about 15 minutes.

## Checklist

- [ ] Get a Claude Pro subscription
- [ ] Install the Claude desktop app and sign in
- [ ] Check that the **Code** tab works
- [ ] Install Obsidian

## 1. Get a Claude subscription

We use **Claude Code**, which needs a **Claude Pro** subscription (about $20/month). The free tier does **not** work.

Sign up at [claude.ai](https://claude.ai).

**How many licenses?**

- **Minimum:** one subscription per group.
- **My recommendation:** one subscription per person. Being able to try things on your own saves a tremendous amount of time, in the lecture, in your studies, and later in your career.
- If your budget is tight, one license per group is completely fine.

## 2. Install the Claude desktop app

In the lecture we use the **Claude desktop app** by default.

**Mac**

1. Download the app from [claude.ai/download](https://claude.ai/download)
2. Open the downloaded file and drag Claude into your Applications folder
3. Launch Claude and sign in with your Pro account

**Windows (10 or newer)**

1. Download the installer from [claude.ai/download](https://claude.ai/download)
2. Run the installer and follow the steps
3. Launch Claude and sign in with your Pro account

No terminal, Node.js or other tools needed.

**Linux users:** there is no desktop app, use the terminal version (see below).

### Check that it works

1. Open Claude and start a new chat. If Claude answers, you are signed in.
2. Click the **Code** tab in the upper left. If it opens, Claude Code is ready.

### Prefer the terminal?

You can also run Claude Code in the terminal (Claude Code CLI) instead of the desktop app. Both work for the lecture. Instructions: [Claude Code CLI guide](https://ccforpms.com/getting-started/start-and-clone#prefer-the-terminal-claude-code-cli)

## 3. Install Obsidian

[Obsidian](https://obsidian.md/) is a free editor for Markdown files. We use it to read and write the notes and documents that Claude creates.

Download: [obsidian.md/download](https://obsidian.md/download)

Good to know:

- An Obsidian "vault" is just a normal folder on your computer.
- Obsidian does not show hidden folders such as `.claude/`. Use Finder (Mac) or Explorer (Windows) for those.
- You will work with two windows side by side: Obsidian for the Markdown files, Claude for the work.

New to Obsidian or Markdown? See [Obsidian Basics](../help/obsidian-basics.md) and [Markdown Basics](../help/markdown-basics.md).
