# Obsidian Basics

## What is Obsidian?

Obsidian is an editor for Markdown files with a built-in file browser. A "vault" is simply a folder on your computer. Everything you see in Obsidian is a normal file that you can also find in Finder/Explorer.

## The most important shortcuts

| Shortcut (Mac) | Shortcut (Windows) | Action                                        |
| -------------- | ------------------ | --------------------------------------------- |
| `Cmd+P`        | `Ctrl+P`           | **Command palette** -- search all commands    |
| `Cmd+N`        | `Ctrl+N`           | Create a new file                             |
| `Cmd+,`        | `Ctrl+,`           | Open settings                                 |
| `Cmd+O`        | `Ctrl+O`           | Quick open a file (search)                    |
| `Cmd+S`        | `Ctrl+S`           | Save (also happens automatically)             |

> **Tip:** The command palette (`Cmd+P`) is your best friend. If you don't know where a feature is, search for it there.

## File browser (left sidebar)

- Click the **folder icon** in the top left
- Here you see all files and folders in your vault
- Right-click for options (rename, delete, new folder)
- Move files by drag and drop

## Editing view vs. reading view

- **Editing view:** You see the Markdown source and can edit it
- **Reading view:** You see the formatted result
- Switch with `Cmd+E` or the book icon in the top right

## Finding files

- `Cmd+O` opens quick search -- type the file name
- `Cmd+Shift+F` searches the content of all files

## Where are my files?

Everything lives in your vault folder (e.g. `AI Strategy Lecture`). Obsidian also creates a `.obsidian` folder for its settings. Your files belong to you -- you can edit them outside Obsidian at any time.
